
  # Chatbot app UI design

  This is a code bundle for Chatbot app UI design. The original project is available at https://www.figma.com/design/Ta0gbE1ebYdM3zNl9zwPXt/Chatbot-app-UI-design.

  ## Running the code

  ## Database update for multi-chatbot support

  Before running the app with multi-chatbot functionality, execute the SQL in [supabase_multi_chatbot.sql](supabase_multi_chatbot.sql) in Supabase SQL Editor.

  For additional chatbot capabilities (settings and knowledge sources), also execute [supabase_chatbot_features.sql](supabase_chatbot_features.sql).

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
